# 번역 지침

- 외부 기계 번역을 쓰지 않고 직접 번역했습니다.
- 첩보 액션 분위기에 맞춰 무전 대사는 짧고 단호한 구어체로, 브리핑·정보 문서·게이브의 일지는 보고서체·독백체로 씁니다. 팀원이 게이브에게는 존댓말, 게이브가 팀원에게는 반말을 씁니다.
- 인명·조직명은 한글로 음역하고(게이브 로건, 테레사, 리안 싱, 에이전시 등), 실제 총기 모델명·코드명은 영어 그대로 둡니다.
- 메뉴·버튼은 짧은 명사형, 목표 문장은 간결한 명사형으로 씁니다.
- 버튼 기호·서식 코드(`<p:3.0>` `<c:…>` `%d` 등)·줄바꿈·맨 앞 `@` 는 원문 그대로 유지합니다.
- **MRK 음성 자막은 원래 바이트 길이 안에** 들어가야 합니다(한글 1자 = 2바이트). 넘치면 `mrk_short.json` 에 줄인 번역을 넣습니다.
- 실행 파일 문자열(`prx_str.json`)도 원래 자리 길이를 넘을 수 없습니다.
- 쓸 수 있는 글자는 한글 완성형 음절과 ASCII입니다. 특수 문장 부호는 ASCII로 바꿉니다.
